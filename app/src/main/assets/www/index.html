Mã Hugging Face

Miễn phí nhưng mỗi tài khoản chỉ khoảng 3 bài/ngày. Lấy mã: huggingface.co → Settings → Access Tokens → tạo mã loại "Read".

  1. Bấm nút dưới để mở trang Colab (đăng nhập Gmail).
  2. Lần đầu: menu Runtime → Change runtime type → T4 GPU → Save.
  3. Bấm Runtime → Run all, chờ 5–10 phút.
  4. Chép LINK MÁY CHỦ (…trycloudflare.com) dán vào ô dưới.
🚀 Mở trang Colab

Giữ trang Colab mở trong lúc dùng. Colab miễn phí tự tắt sau vài giờ; khi đó chạy lại và dán link mới.

  1. Bấm nút dưới để mở Hugging Face, đăng ký tài khoản miễn phí (hoặc đăng nhập).
